# MT5 SQL Export — Trading Core Tables

Field catalog for the MetaTrader 5 Backup Server SQL Export tables in the trading core
domain: `mt5_orders`, `mt5_deals`, `mt5_positions`, `mt5_orders_history`, `mt5_prices`,
`mt5_daily`, `mt5_daily_orders`, `mt5_daily_positions`.

Conventions used below:

- **PK/FK** — `**PK**` marks the documented primary key. FK entries are logical
  (MT5 export does not declare constraints): `Login` -> users/accounts, `Order` -> orders,
  `PositionID` -> positions, `Symbol` -> symbols, `Dealer` -> managers/dealers, `Group` -> groups.
- **Enum** — the MT5 enumeration whose values the integer column carries.
- Volume units: unless stated otherwise, `Volume*` columns use 1 unit = 1/10000 lot;
  the `*Ext` variants use 1 unit = 1/100000000 lot.

## Table-level behaviors

- **Per-year partitioning.** If the backup server option *"Export history orders and deals
  into separate tables by years"* is enabled, `mt5_deals` and `mt5_orders_history` are split
  per year: `mt5_deals_2012`, `mt5_orders_2012`, etc. If disabled, everything goes into the
  single `mt5_deals` / `mt5_orders_history` table.
- **`Position_ID` vs `Position`.** In `mt5_positions`, the primary key `Position_ID` is an
  internal identifier generated by the backup server for export purposes only — it is *not*
  a trading ticket. The real MT5 position ticket is in the `Position` column; join
  `mt5_orders.PositionID` / `mt5_deals.PositionID` against `Position`, never `Position_ID`.
- **Daily snapshot tables.** `mt5_daily_orders` and `mt5_daily_positions` are only generated
  if the backup server setting *"Export additional columns for daily reports \ Orders from
  daily reports"* is enabled. Both carry an extra `Datetime` column: the date the end-of-day
  status was snapshotted.
- **Price refresh cadence.** `mt5_prices` update frequency depends on the backup server's
  *"Refresh prices and trade profits every N minutes"* setting.
- **`Timestamp`** exists on every trading table: an internal MT5 record version; a changed
  value means the record was modified.
- **Build caveat.** `mt5_deals.MarketBid` / `MarketAsk` / `MarketLast` are only populated for
  deals created after the platform was updated to build 2890 or higher (zero before that).
