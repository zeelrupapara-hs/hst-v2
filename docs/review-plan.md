# Backend review plan — agent team

Goal: end-to-end review of the Go backend before a junior developer joins. Every agent loads
`.claude/skills/hst-go-review/SKILL.md` first, reads its files fully, traces its flows across
module boundaries, and writes `docs/review/<nn>-<area>.md`. Findings carry `path:line`.
Nothing is fixed during the review. Frontend is out of scope.
